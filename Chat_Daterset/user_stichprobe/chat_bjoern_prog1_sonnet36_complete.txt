   # Reading from the Console in Java
   
   To read values from the console in Java, there are multiple methods available, but they all require an understanding of object-oriented programming. Unlike some other programming languages, Java does not have a simple and native mechanism for console input.
   
   ## Prog1Tools Library
   
   To simplify console input, we have encapsulated the standard Java mechanisms in the **Prog1Tools** library. Within this library, the **IOTools** class provides straightforward methods for reading various types of values. The naming convention for these methods follows a specific pattern, for example:
   
   - `readInt()`
   - `readDouble()`
   - `readString()`
   
   For reading strings, there are actually two methods: `readLine()` and `readWord()`.
   
   - **`readLine()`** reads an entire line (i.e., until the user hits Enter/Return).
   - **`readWord()`** reads a single word (i.e., any whitespace character will terminate the input).
   
   ### Example Usage
   
   If we want to read an integer, we would call:
   
   ```java
   int userInput = IOTools.readInt();
   ```
   
   This expression evaluates to the integer value that the user typed, which can then be used for further processing, such as assigning it to a variable or printing it to the console.
   
   ## Additional Features of IOTools
   
   The **IOTools** methods come with two additional features:
   
   1. **Input Validation**: When reading an integer, users will be prompted to type an integer number. If they type anything else (e.g., a boolean), the method will reprompt the user.
   
   2. **Custom Prompt**: Each method has a variant that accepts a string parameter. This parameter can be a complex expression, a literal, another method call, or simply the name of a variable.

## Was ist eine Variable?

Stell dir eine Variable vor wie eine **beschriftete Schachtel** in deinem Zimmer.

- Die Schachtel hat einen **Namen** (z.B. `name`) – damit du weißt, was drin ist
- Die Schachtel hat eine **Größe/Art** (den *Typ*) – eine Schachtel für Schuhe ist anders als eine für Briefe
- In der Schachtel liegt ein **Wert** – also der eigentliche Inhalt

In Java sieht das so aus:

```java
String name = "Björn";
```

Das bedeutet:
| Teil | Bedeutung | Analogie |
|------|-----------|----------|
| `String` | *Art* der Schachtel | "Diese Schachtel ist für Text" |
| `name` | *Name* der Schachtel | Aufkleber auf der Schachtel |
| `=` | "bekommt den Wert" | Du legst etwas rein |
| `"Björn"` | *Inhalt* der Schachtel | Was tatsächlich drin liegt |

## Was ist ein String?

Ein **String** ist einfach gesagt: **Text**.

Immer wenn du in Java Text speichern willst – egal ob ein Name, ein Satz oder ein einzelner Buchstabe – benutzt du den Typ `String`.

**Wichtige Regel:** Text in Java muss immer in **Anführungszeichen** stehen:
```java
String begruessung = "Hallo Welt";
String name = "Björn";
```

Zahlen hingegen brauchen **keine** Anführungszeichen:
```java
int alter = 22;
```

> 💡 `int` ist der Typ für ganze Zahlen – dazu kommen wir später noch!

   ### Overview of Object-Oriented Programming
   
   Object-Oriented Programming (OOP) is a programming paradigm that uses "objects" to represent data and methods to manipulate that data. The key concepts of OOP include:
   
   - **Classes and Objects**
   - **Encapsulation**
   - **Inheritance**
   - **Polymorphism**
   
   ### 1. Classes and Objects
   
   A class is a blueprint for creating objects. An object is an instance of a class.
   
   ```python
   class Dog:
   def __init__(self, name):
   self.name = name
   
   def bark(self):
   return f"{self.name} says woof!"
   
   # Creating an object of the Dog class
   my_dog = Dog("Buddy")
   print(my_dog.bark())  # Output: Buddy says woof!
   ```
   
   ### 2. Encapsulation
   
   Encapsulation is the bundling of data and methods that operate on that data within one unit, typically a class. It restricts direct access to some of the object's components.
   
   ```python
   class BankAccount:
   def __init__(self, balance=0):
   self.__balance = balance  # Private attribute
   
   def deposit(self, amount):
   self.__balance += amount
   
   def get_balance(self):
   return self.__balance
   
   account = BankAccount()
   account.deposit(100)
   print(account.get_balance())  # Output: 100
   ```
   
   ### 3. Inheritance
   
   Inheritance allows a class to inherit attributes and methods from another class.
   
   ```python
   class Animal:
   def speak(self):
   return "Animal speaks"
   
   class Cat(Animal):
   def speak(self):
   return "Cat meows"
   
   my_cat = Cat()
   print(my_cat.speak())  # Output: Cat meows
   ```
   
   ### 4. Polymorphism
   
   Polymorphism allows methods to do different things based on the object it is acting upon.
   
   ```python
   def animal_sound(animal):
   print(animal.speak())
   
   animal_sound(my_cat)  # Output: Cat meows
   animal_sound(Dog("Rex"))  # Output: Rex says woof!
   ```
   
   ### Summary
   
   Object-Oriented Programming is a powerful paradigm that helps in organizing code and making it more reusable and maintainable.

   ### Short-Circuit Evaluation
   
   What is the difference between the two options for AND and OR? In many cases, the first operand will already decide the outcome of the expression.    # Java Programming Basics
   
   ## Class Definition
   
   In Java, every program is defined within a class. The class name should start with an uppercase letter and follow the naming conventions. The curly braces `{}` open a block (which is closed later) to define which code lines belong to the class.
   
   ```java
   public class HelloWorld {
   // Class content goes here
   }
   ```
   
   ## Main Method
   
   The main method is the entry point of any Java program. When the Java Virtual Machine (JVM) starts executing the program, it begins with the main method.
   
   ```java
   public static void main(String[] args) {
   // Main method content goes here
   }
   ```
   
   ### Indentation and Readability
   
   - The main method starts one tab character to the right, and code lines within the main method start yet another tab character to the right.
   - In Java, indentation is used strictly for readability. Additional whitespace characters (such as tabs or spaces) are ignored by the compiler.
   - Use the auto-format command in IntelliJ to maintain proper formatting.
   
   ## Comments
   
   Comments are essential for explaining code. Java provides three types of comments:
   
   1. **End-of-line comment**: Starts with `//` and continues until the end of the line.
   ```java
   int x = 5; // This is an end-of-line comment
   ```
   
   2. **Multi-line comment**: Starts with `/*` and ends with `*/`.
   ```java
   /* This is a
   multi-line comment */
   ```
   
   3. **Javadoc comment**: Starts with `/**` and ends with `*/`.
