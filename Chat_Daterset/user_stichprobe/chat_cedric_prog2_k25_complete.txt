## For-Comprehension: Die Grundidee

Die for-comprehension ist Scalas elegante Syntax, um mit **Collections** (Listen, Arrays, Iterator, etc.) zu arbeiten. Sie ersetzt verschachtelte Schleifen und macht den Code lesbarer.

### Grundstruktur

```scala
for {
    element <- collection    // Generator: holt jedes Element aus der Collection
    if condition             // Filter (optional): nur wenn Bedingung wahr
} yield transformation       // yield: Ergebnis zurückgeben
```

---

## Ein einfaches Beispiel

```scala
val numbers = List(1, 2, 3, 4, 5)

// Alle Zahlen verdoppeln
val doubled = for {
    n <- numbers
} yield n * 2

// Ergebnis: List(2, 4, 6, 8, 10)
```

Mit **Filter**:
```scala
// Nur gerade Zahlen verdoppeln
val doubledEvens = for {
    n <- numbers
    if n % 2 == 0
} yield n * 2

// Ergebnis: List(4, 8)
```

---

## Mehrere Generatoren (verschachtelt)

Du kannst mehrere `<-` verwenden – das entspricht verschachtelten Schleifen:

```scala
val list1 = List(1, 2)
val list2 = List("a", "b")

val combinations = for {
    num <- list1      // Äußere Schleife
    str <- list2      // Innere Schleife
} yield (num, str)

// Ergebnis: List((1,"a"), (1,"b"), (2,"a"), (2,"b"))
```

---

## Wichtig: `yield` vs. `do` (Seiteneffekte)

| Mit `yield` | Ohne `yield` (nur Seiteneffekte) |
|-------------|----------------------------------|
| Gibt eine **neue Collection** zurück | Führt Aktionen aus, gibt **Unit** zurück |
| `for { ... } yield result` | `for { ... } do println(...)` |

## Zurück zu deiner Aufgabe: `readRegistrationsFromFile`

Du hast:
- `lines` – ein `Iterator[String]` mit Zeilen wie `"Willi,373583,2"`
- Ziel: Jede Zeile in ein Tupel `(String, Int, Int)` verwandeln

**Schritt-für-Schritt:**

```scala
for {
    line <- lines                    // Jede Zeile einzeln
    values = line.split(",").map(_.trim)  // Aufteilen und trimmen
} yield (values(0), values(1).toInt, values(2).toInt)
```

**Was passiert hier?**

| Schritt | Ergebnis für `"Willi,373583,2"` |
|---------|--------------------------------|
| `line <- lines` | `"Willi,373583,2"` |
| `line.split(",")` | `Array("Willi", "373583", "2")` |
| `.map(_.trim)` | `Array("Willi", "373583", "2")` (hier bereits sauber) |
| `yield (...)` | `("Willi", 373583, 2)` |

Das `yield` sammelt alle Tupel in eine neue Collection. Da `lines` ein `Iterator` ist, wird ein `Iterator` zurückgegeben – daher brauchst du am Ende `.toList`.



| Teil | Bedeutung |
|------|-----------|
| `(_, id1, attempt) <- registrations` | Name ignorieren, Matrikelnummer und Versuch extrahieren |
| `if attempt == 2` | Nur Zweitversuch |

| `yield grade` | Nur die Note zurückgeben (kein Tupel nötig!) |
| `grades.sum` | Summe aller Noten |
| `grades.size` | Anzahl der Noten |
| `sum / size` | Durchschnitt |

**Wichtig:** Hier ist `yield grade` statt `yield (name, grade)` – wir brauchen nur die Note für die Berechnung, nicht den Namen.
