## Die absoluten Grundlagen: Was ist Programmieren?

**Programmieren bedeutet:** Du schreibst Anweisungen für den Computer, die er Schritt für Schritt ausführt. Das machst du in einer **Programmiersprache** – in diesem Kurs ist das **Java**.

### Das Grundgerüst eines Java-Programms

Jedes Java-Programm braucht mindestens das hier:

```java
public class HelloWorld {
    public static void main(String[] args) {
        // Hier kommen deine Anweisungen hin
    }
}
```

**Was bedeutet das?**

| Teil | Bedeutung |
|------|-----------|
| `public class HelloWorld` | Du erstellst eine "Klasse" (eine Art Bauplan) namens `HelloWorld`. Der Name muss mit dem Dateinamen übereinstimmen. |
| `public static void main(...)` | Die `main`-Methode – das ist der **Einstiegspunkt**. Hier fängt das Programm an zu laufen. |
| `String[] args` | Kannst du erstmal ignorieren, das brauchen wir später. |

---

## Erste wichtige Konzepte: Variablen

Eine **Variable** ist wie eine Schublade mit einem Namen, in der du einen Wert speicherst.

```java
String name = "Leroy";
```

| Teil | Bedeutung |
|------|-----------|
| `String` | Der **Datentyp** – hier: Text (Zeichenkette) |
| `name` | Der **Name** der Variable (Identifier) – frei wählbar |
| `"Leroy"` | Der **Wert**, der gespeichert wird |
| `=` | Der **Zuweisungsoperator** – schreibt den Wert in die Variable |

---

## Ausgabe auf der Konsole

Um etwas auszugeben, verwendest du:

```java
System.out.println("Hallo!");
```

Das druckt den Text auf den Bildschirm. Du kannst auch Variablen einbauen:

```java
System.out.println("Hallo " + name + "!");
```

Das `+` hier verbindet Textstücke – das nennt man **String-Konkatenation**.

   ### Overview of Object-Oriented Programming
   
   Object-Oriented Programming (OOP) is a programming paradigm that uses "objects" to represent data and methods to manipulate that data. The key concepts of OOP include:
   
   - **Classes and Objects**
   - **Encapsulation**
   - **Inheritance**
   - **Polymorphism**
   
   ### 1. Classes and Objects
   
   A class is a blueprint for creating objects. An object is an instance of a class.
   
   ```python
   class Dog:
   def __init__(self, name):
   self.name = name
   
   def bark(self):
   return f"{self.name} says woof!"
   
   # Creating an object of the Dog class
   my_dog = Dog("Buddy")
   print(my_dog.bark())  # Output: Buddy says woof!
   ```
   
   ### 2. Encapsulation
   
   Encapsulation is the bundling of data and methods that operate on that data within one unit, typically a class. It restricts direct access to some of the object's components.
   
   ```python
   class BankAccount:
   def __init__(self, balance=0):
   self.__balance = balance  # Private attribute
   
   def deposit(self, amount):
   self.__balance += amount
   
   def get_balance(self):
   return self.__balance
   
   account = BankAccount()
   account.deposit(100)
   print(account.get_balance())  # Output: 100
   ```
   
   ### 3. Inheritance
   
   Inheritance allows a class to inherit attributes and methods from another class.
   
   ```python
   class Animal:
   def speak(self):
   return "Animal speaks"
   ```
