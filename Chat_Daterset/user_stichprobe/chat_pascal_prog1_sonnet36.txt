## 🧱 Das absolute Fundament: Was ist Java überhaupt?

Bevor wir in die Aufgaben einsteigen, kurz das Wichtigste:

Java ist eine **Programmiersprache**. Ein Java-Programm ist im Grunde eine Liste von Anweisungen, die der Computer **von oben nach unten** abarbeitet. Jedes Java-Programm braucht eine sogenannte **`main`-Methode** – das ist der Startpunkt, von dem aus alles läuft:

```java
public class HelloWorld {
    public static void main(String[] args) {
        // Hier stehen die Anweisungen
    }
}
```

Stell dir das so vor:
- `public class HelloWorld` → Das ist der **Name deines Programms** (muss mit dem Dateinamen übereinstimmen)
- `public static void main(String[] args)` → Das ist die **Starttaste** – hier beginnt die Ausführung
- Die geschweiften Klammern `{ }` → Alles darin **gehört zusammen**

---

## 🔑 Kern-Konzept: Variablen

Eine **Variable** ist wie eine **beschriftete Schachtel**, in der du einen Wert aufbewahrst.

```java
String name = "Pascal";
```

Das bedeutet:
- `String` → Der **Typ** der Schachtel (hier: Text)
- `name` → Der **Name** der Schachtel
- `"Pascal"` → Der **Inhalt**

Wichtige Typen, die in der Hausaufgabe vorkommen:

| Typ | Bedeutung | Beispiel |
|---|---|---|
| `String` | Text | `"Hallo"` |
| `int` | Ganze Zahl (klein) | `42` |
| `long` | Ganze Zahl (sehr groß) | `23476234688` |
| `double` | Kommazahl | `3.14` |

---

## 🖨️ Ausgabe auf der Konsole

Um etwas auszugeben, schreibt man:

```java
System.out.println("Hello Pascal!");
```

Und um eine Variable mit einzubauen, **verbindet** man Text und Variable mit `+`:

```java
String name = "Pascal";
System.out.println("Hello " + name + "!");
// Ausgabe: Hello Pascal!
```

## 📌 Aufgabe 1.4 – Zeitumrechnung

### Was sollst du tun?
Der Benutzer gibt eine große Zahl in **Sekunden** ein (z.B. 23.476.234.688 Sekunden), und dein Programm rechnet das um in **Jahre, Tage, Stunden, Minuten, Sekunden**.

### Das neue Konzept: Division & Modulo

Das sind die zwei wichtigsten Rechenoperationen hier:

**Ganzzahlige Division `/`** → Wie oft passt etwas rein?
```
100 Sekunden / 60 = 1  (→ 1 volle Minute)
```

**Modulo `%`** → Was bleibt übrig?
```
100 Sekunden % 60 = 40  (→ 40 Sekunden Rest)
```

**Die Strategie** ist immer dieselbe – von groß nach klein:
```
Gesamtsekunden → geteilt durch (60×60×24×365) = Jahre
Rest → geteilt durch (60×60×24) = Tage
Rest → geteilt durch (60×60) = Stunden
Rest → geteilt durch 60 = Minuten
Rest = Sekunden
```

# Was ist eine Variable? 📦

Super Frage, Pascal – das ist das **absolut wichtigste Konzept** in der Programmierung. Wenn du das verstehst, verstehst du den Kern von allem!

---

## Die Schachtel-Analogie

Stell dir deinen Computer-Speicher (RAM) vor wie ein **riesiges Regal mit Millionen von Schachteln**. Jede Schachtel kann einen Wert speichern.

Eine **Variable** ist eine dieser Schachteln – mit drei wichtigen Eigenschaften:

```
┌─────────────────────────┐
│  Name:   name           │  ← Wie heißt die Schachtel?
│  Typ:    String         │  ← Was darf rein?
│  Inhalt: "Pascal"       │  ← Was ist drin?
└─────────────────────────┘
```

In Java schreibt man das so:
```java
String name = "Pascal";
```

Das sind genau **3 Teile**:

| Teil | Beispiel | Bedeutung |
|---|---|---|
| Typ | `String` | **Was für eine** Schachtel ist das? |
| Name | `name` | **Wie heißt** die Schachtel? |
| Wert | `"Pascal"` | **Was liegt** in der Schachtel? |

---

## Warum braucht man Typen?

Nicht jede Schachtel passt für alles. Java kennt verschiedene "Schachtel-Größen":

```
String name = "Pascal";      → Schachtel für Text
int alter = 20;              → Schachtel für kleine ganze Zahlen
long sekunden = 23476234688; → Schachtel für sehr große ganze Zahlen
double temperatur = 36.6;    → Schachtel für Kommazahlen
```

**Warum ist das wichtig?**
Der Computer muss wissen, wie viel Speicherplatz er reservieren soll. Eine Kommazahl braucht mehr Platz als ein einfaches Ja/Nein.

---

## Was kann man mit einer Variable machen?

### 1️⃣ Wert reinlegen (Zuweisung)
```java
String name = "Pascal";   // Schachtel erstellen & befüllen
```

### 2️⃣ Wert verändern
```java
name = "Max";   // Alten Inhalt rauswerfen, neuen reinlegen
// Jetzt steht "Max" in der Schachtel, "Pascal" ist weg
```

### 3️⃣ Wert auslesen (benutzen)
```java
System.out.println(name);   // Java schaut in die Schachtel und nimmt den Wert raus
// Ausgabe: Max
```

---

## Konkretes Beispiel aus deiner Hausaufgabe

In **Aufgabe 1.2** machst du genau das:

```java
String name = "Pascal";                    // Schachtel erstellen
System.out.println("Hello " + name + "!"); // Schachtel auslesen
```

Java liest beim `+` automatisch den Inhalt der Schachtel aus und klebt ihn zusammen:
```
"Hello "  +  "Pascal"  +  "!"
              ↑
         Inhalt der Schachtel "name"
              ↓
"Hello Pascal!"
```

---

## Die wichtigste Regel: Typ muss passen! ❗

```java
int zahl = "Pascal";   // ❌ FEHLER! Text passt nicht in eine Zahlen-Schachtel
String name = 42;      // ❌ FEHLER! Zahl passt nicht in eine Text-Schachtel
String name = "42";    // ✅ OK! "42" als Text ist erlaubt
```

---

Kurz zusammengefasst in einem Satz:

> **Eine Variable ist ein benannter Speicherplatz, der einen Wert eines bestimmten Typs aufbewahrt – wie eine beschriftete Schachtel im Regal deines Computers.**

### 🎯 Was soll das Programm tun?
Der Benutzer gibt eine riesige Zahl in Sekunden ein, und das Programm rechnet diese um in **Jahre, Tage, Stunden, Minuten und Sekunden**.

**Beispiel:**
```
Eingabe:  23476234688 Sekunden
Ausgabe:  744 Jahr(e), 155 Tag(e), 16 Stunde(n), 18 Minute(n) und 8 Sekunde(n)
```

---

## 🔑 Das neue Konzept: Division & Modulo

Bevor wir den Code anschauen, musst du zwei Rechenoperationen verstehen:

### Ganzzahlige Division `/`
→ **Wie oft passt etwas komplett rein?**
```
100 / 60 = 1     (60 passt einmal komplett in 100)
```

### Modulo `%`
→ **Was bleibt übrig?**
```
100 % 60 = 40    (nach der Division bleiben 40 übrig)
```

**Zusammen ergeben sie ein vollständiges Bild:**
```
100 Sekunden = 1 Minute (Division) + 40 Sekunden Rest (Modulo)
```

---

## 🧮 Die Strategie: Von groß nach klein

Wir arbeiten uns immer von der **größten Einheit zur kleinsten** vor:

```
Schritt 1: Sekunden → Jahre       (teilen durch 60×60×24×365)
Schritt 2: Rest → Tage            (teilen durch 60×60×24)
Schritt 3: Rest → Stunden         (teilen durch 60×60)
Schritt 4: Rest → Minuten         (teilen durch 60)
Schritt 5: Rest → Sekunden        (was übrig bleibt)
```

---

## 📖 Der vollständige Code – Zeile für Zeile

```java
import Prog1Tools.IOTools;

public class Zeitumrechnung {
    public static void main(String[] args) {

        // Schritt 1: Eingabe einlesen
        long sec = IOTools.readLong("Geben Sie eine Zeitdauer in Sekunden ein:");

        // Schritt 2: Jahre berechnen
        long y = sec / (60 * 60 * 24 * 365);   // Wie viele volle Jahre?
        sec = sec % (60 * 60 * 24 * 365);       // Was bleibt übrig?

        // Schritt 3: Tage berechnen
        long d = sec / (60 * 60 * 24);          // Wie viele volle Tage?
        sec = sec % (60 * 60 * 24);             // Was bleibt übrig?

        // Schritt 4: Stunden berechnen
        long h = sec / (60 * 60);               // Wie viele volle Stunden?
        sec = sec % (60 * 60);                  // Was bleibt übrig?

        // Schritt 5: Minuten berechnen
        long min = sec / 60;                    // Wie viele volle Minuten?
        sec = sec % 60;                         // Was bleibt übrig?

        // Schritt 6: Ausgabe
        System.out.println("Das sind: " + y + " Jahr(e), " + d + 
        " Tag(e), " + h + " Stunde(n), " + min + " Minute(n) und " + 
        sec + " Sekunde(n).");
    }
}
```

## 🎯 Was soll das Programm tun?

Der Benutzer gibt eine Zahl ein, und das Programm berechnet die **Quadratwurzel** davon:

```
Eingabe:  64

```

---

## 🔑 Zwei neue Konzepte

### 1. `Math.sqrt()` – Wurzel berechnen
Java hat eine eingebaute Mathematik-Bibliothek namens `Math`. Damit kannst du die Wurzel einer Zahl berechnen:

```java
double wurzel = Math.sqrt(64);   // wurzel = 8.0
```

> `Math.sqrt` bedeutet wörtlich: "Mathematik, berechne die Quadratwurzel!" Das Ergebnis ist immer eine Kommazahl (`double`) – deshalb `double wurzel`.

---

### 2. Typecast – Kommazahl → Ganzzahl
`Math.sqrt` gibt immer eine Kommazahl zurück (`8.0`), aber die Aufgabe will eine **ganze Zahl** (`8`). Dafür benutzt man einen **Typecast**:

```java
double wurzel = 8.0;
int ganzzahl = (int) wurzel;   // ganzzahl = 8
//              ↑
//         Das ist der Typecast – du sagst Java: "Behandle das als int"
```

> Der Typecast schneidet einfach die Nachkommastellen ab:
> ```
> 8.9  → (int) → 8    (nicht gerundet, einfach abgeschnitten!)
> 8.1  → (int) → 8
> ```

---

## 📖 Der vollständige Code:

```java
import Prog1Tools.IOTools;

public class Wurzel {
    public static void main(String[] args) {
        int num = IOTools.readInt("Geben Sie eine Zahl ein:");
        double wurzel = Math.sqrt(num);
        System.out.println("Die Wurzel aus " + num + " ist " + (int) wurzel + ".");
    }
}
```

---

## 🔍 Zeile für Zeile erklärt:

**`int num = IOTools.readInt("Geben Sie eine Zahl ein:")`**
> Kennst du schon! Diesmal lesen wir eine `int` Zahl ein – also eine normale kleine ganze Zahl.

---

**`double wurzel = Math.sqrt(num);`**
> Java berechnet die Wurzel von `num` und speichert das Ergebnis in `wurzel`. Das Ergebnis ist eine Kommazahl (`double`).

---

**`System.out.println("Die Wurzel aus " + num + " ist " + (int) wurzel + ".");`**
> Bei der Ausgabe wird `(int) wurzel` direkt in der Ausgabe umgewandelt – die Nachkommastellen werden abgeschnitten:
> ```
> wurzel = 8.0  →  (int) wurzel = 8
> ```

---

## ▶️ Programmablauf:

```
Eingabe:  64
             ↓

             ↓

             ↓

```

        long y   = sec / (60 * 60 * 24 * 365);   // Volle Jahre
        sec      = sec % (60 * 60 * 24 * 365);   // Rest nach Jahren

        long d   = sec / (60 * 60 * 24);          // Volle Tage
        sec      = sec % (60 * 60 * 24);          // Rest nach Tagen

        long h   = sec / (60 * 60);               // Volle Stunden
        sec      = sec % (60 * 60);               // Rest nach Stunden

        long min = sec / 60;                      // Volle Minuten
        sec      = sec % 60;                      // Rest = Sekunden

        System.out.println("Das sind: " + y + " Jahr(e), " + d + 
        " Tag(e), " + h + " Stunde(n), " + min + " Minute(n) und " + 
        sec + " Sekunde(n).");
    }
}
