## Was ist eine Variable?

Stell dir eine Variable vor wie eine **beschriftete Schachtel** in deinem Zimmer.

- Die Schachtel hat einen **Namen** (z.B. `name`) – damit du weißt, was drin ist
- Die Schachtel hat eine **Größe/Art** (den *Typ*) – eine Schachtel für Schuhe ist anders als eine für Briefe
- In der Schachtel liegt ein **Wert** – also der eigentliche Inhalt

In Java sieht das so aus:

```java
String name = "Björn";
```

Das bedeutet:
| Teil | Bedeutung | Analogie |
|------|-----------|----------|
| `String` | *Art* der Schachtel | "Diese Schachtel ist für Text" |
| `name` | *Name* der Schachtel | Aufkleber auf der Schachtel |
| `=` | "bekommt den Wert" | Du legst etwas rein |
| `"Björn"` | *Inhalt* der Schachtel | Was tatsächlich drin liegt |

---

## Was ist ein String?

Ein **String** ist einfach gesagt: **Text**.

Immer wenn du in Java Text speichern willst – egal ob ein Name, ein Satz oder ein einzelner Buchstabe – benutzt du den Typ `String`.

**Wichtige Regel:** Text in Java muss immer in **Anführungszeichen** stehen:
```java
String begruessung = "Hallo Welt";
String name = "Björn";
```

Zahlen hingegen brauchen **keine** Anführungszeichen:
```java
int alter = 22;
```

> 💡 `int` ist der Typ für ganze Zahlen – dazu kommen wir später noch!

---

## Zusammenfassung in einem Satz

> Eine **Variable** ist ein benannter Speicherplatz für einen Wert. Ein **String** ist der Typ für diesen Speicherplatz, wenn der Wert **Text** sein soll.

## 1. Die main-Methode – Das "Starttor" des Programms

Jedes Java-Programm braucht einen festgelegten Startpunkt. Der heißt `main`-Methode. Java schaut immer zuerst hier rein und führt alles aus, was darin steht:

```java
public static void main(String[] args) {
    // Hier passiert alles
}
```

Die geschweifte Klammer `{` bedeutet "hier fängt der Bereich an", `}` bedeutet "hier hört er auf". Was dazwischen steht, wird ausgeführt.

---

## 2. System.out.println – Die "Druckfunktion"

Um Text auf dem Bildschirm auszugeben, benutzt Java diesen Befehl:

```java
System.out.println("Irgendein Text");
```

Das `ln` am Ende bedeutet, dass danach eine neue Zeile beginnt – wie Enter drücken.

---

```java
public class HelloWorld {

    public static void main(String[] args) {
        String name = "Björn";
        System.out.println("Hello " + name + "!");
    }

}
```

---

## Was passiert hier Schritt für Schritt?

| Zeile | Was passiert |
|-------|-------------|
| `public class HelloWorld {` | Wir öffnen die "Hülle" des Programms |
| `public static void main(String[] args) {` | Das Starttor – Java fängt hier an |
| `String name = "Björn";` | Schachtel `name` wird angelegt, Inhalt: "Björn" |
| `System.out.println(...)` | Ausgabe auf dem Bildschirm |
| `"Hello " + name + "!"` | Textstücke werden zusammengeklebt |
| `}` und `}` | Schließen der main-Methode und der Klasse |

**Ausgabe wäre:**
```
Hello Björn!
```
