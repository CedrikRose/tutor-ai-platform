   ### 1. Introduction to Programming
   Programming is the process of creating a set of instructions that tell a computer how to perform a task. It involves writing code in a programming language.
   
   ### 2. Basic Concepts
   - **Variables**: Used to store data values.
   - **Data Types**: Different types of data (e.g., integers, floats, strings).
   - **Operators**: Symbols that perform operations on variables and values.
   
   #### Example:
   ```python
   # This is a comment
   x = 5           # Integer
   y = 3.14        # Float
   name = "Alice"  # String
   ```
   
   ### 3. Control Structures
   Control structures dictate the flow of control in a program. The most common types are:
   - **Conditional Statements**: `if`, `else`, `elif`
   - **Loops**: `for`, `while`
   
   #### Example:
   ```python
   # Conditional statement
   if x > 0:
   print("x is positive")
   else:
   print("x is non-positive")
   
   # Loop
   for i in range(5):
   print(i)
   ```
   
   ### 4. Functions
   Functions are reusable pieces of code that perform a specific task. They can take inputs and return outputs.
   
   #### Example:
   ```python
   def add(a, b):
   return a + b
   
   result = add(5, 3)
   print(result)  # Output: 8
   ```

   - **Lists**
   - **Tuples**
   - **Dictionaries**
   - **Sets**
   
   #### Example:
   ```python
   # List
   fruits = ["apple", "banana", "cherry"]
   
   # Dictionary
   person = {"name": "Alice", "age": 25}

## 🧱 Das absolute Fundament: Was ist Java überhaupt?

Bevor wir in die Aufgaben einsteigen, kurz das Wichtigste:

Java ist eine **Programmiersprache**. Ein Java-Programm ist im Grunde eine Liste von Anweisungen, die der Computer **von oben nach unten** abarbeitet. Jedes Java-Programm braucht eine sogenannte **`main`-Methode** – das ist der Startpunkt, von dem aus alles läuft:

```java
public class HelloWorld {
    public static void main(String[] args) {
        // Hier stehen die Anweisungen
    }
}
```

Stell dir das so vor:
- `public class HelloWorld` → Das ist der **Name deines Programms** (muss mit dem Dateinamen übereinstimmen)
- `public static void main(String[] args)` → Das ist die **Starttaste** – hier beginnt die Ausführung
- Die geschweiften Klammern `{ }` → Alles darin **gehört zusammen**

## 🔑 Kern-Konzept: Variablen

Eine **Variable** ist wie eine **beschriftete Schachtel**, in der du einen Wert aufbewahrst.

```java
String name = "Pascal";
```

Das bedeutet:
- `String` → Der **Typ** der Schachtel (hier: Text)
- `name` → Der **Name** der Schachtel
- `"Pascal"` → Der **Inhalt**

Wichtige Typen, die in der Hausaufgabe vorkommen:

| Typ | Bedeutung | Beispiel |
|---|---|---|
| `String` | Text | `"Hallo"` |
| `int` | Ganze Zahl (klein) | `42` |
| `long` | Ganze Zahl (sehr groß) | `23476234688` |
| `double` | Kommazahl | `3.14` |

```java
System.out.println("Hello Pascal!");

String name = "Pascal";
System.out.println("Hello " + name + "!");
// Ausgabe: Hello Pascal!

## 📌 Aufgabe 1.4 – Zeitumrechnung

### Was sollst du tun?
Der Benutzer gibt eine große Zahl in **Sekunden** ein (z.B. 23.476.234.688 Sekunden), und dein Programm rechnet das um in **Jahre, Tage, Stunden, Minuten, Sekunden**.

### Das neue Konzept: Division & Modulo

Das sind die zwei wichtigsten Rechenoperationen hier:

**Ganzzahlige Division `/`** → Wie oft passt etwas rein?
```
100 Sekunden / 60 = 1  (→ 1 volle Minute)
```

**Modulo `%`** → Was bleibt übrig?
```
100 Sekunden % 60 = 40  (→ 40 Sekunden Rest)
```

**Die Strategie** ist immer dieselbe – von groß nach klein:
```
Gesamtsekunden → geteilt durch (60×60×24×365) = Jahre
Rest → geteilt durch (60×60×24) = Tage
Rest → geteilt durch (60×60) = Stunden
Rest → geteilt durch 60 = Minuten
Rest = Sekunden
```

   # Example: Call Stacks
   
   ## Recursive Factorial Function
   
   ```java
   public static int fac(int n) {
   if (n == 1) return 1;
   return n * fac(n - 1);
   }
   ```
   
   Calling `int k = fac(5)` in `main` will result in the following call stack:
   
   1. `fac(5)`
   2. `fac(4)`
   3. `fac(3)`
   4. `fac(2)`
   5. `fac(1)`
   
   Each call waits for the result of the next call until it reaches the base case.
   
   ## Iterative Factorial Function
   
   ```java
   public static int fac(int n) {
   int res = 1;
   while (n > 1) res *= n--;
   return res;
   }
   ```
   
   In this version, the factorial is calculated iteratively without using the call stack.
   
   ## Main Function Example
   
   ```java
   public static void main(String[] args) {
   int k = fac(5);
   System.out.println(k);
   }
   ```
   
   This will output `120`, which is the result of `5!`.
   
   ----
   
   ### Summary
   
   - The recursive approach uses the call stack to keep track of function calls.
   - The iterative approach uses a loop and does not involve the call stack.
   - Both methods yield the same result for calculating factorials.

# Was ist eine Variable? 📦

Super Frage, Pascal – das ist das **absolut wichtigste Konzept** in der Programmierung. Wenn du das verstehst, verstehst du den Kern von allem!

---

## Die Schachtel-Analogie

Stell dir deinen Computer-Speicher (RAM) vor wie ein **riesiges Regal mit Millionen von Schachteln**. Jede Schachtel kann einen Wert speichern.

Eine **Variable** ist eine dieser Schachteln – mit drei wichtigen Eigenschaften:

```
┌─────────────────────────┐
│  Name:   name           │  ← Wie heißt die Schachtel?
│  Typ:    String         │  ← Was darf rein?
│  Inhalt: "Pascal"       │  ← Was ist drin?
└─────────────────────────┘
```

In Java schreibt man das so:
```java
String name = "Pascal";
```

Das sind genau **3 Teile**:

| Teil | Beispiel | Bedeutung |
|---|---|---|
| Typ | `String` | **Was für eine** Schachtel ist das? |
| Name | `name` | **Wie heißt** die Schachtel? |
| Wert | `"Pascal"` | **Was liegt** in der Schachtel? |

---

## Warum braucht man Typen?

Nicht jede Schachtel passt für alles. Java kennt verschiedene "Schachtel-Größen":

```
String name = "Pascal";      → Schachtel für Text
int alter = 20;              → Schachtel für kleine ganze Zahlen
long sekunden = 23476234688; → Schachtel für sehr große ganze Zahlen
double temperatur = 36.6;    → Schachtel für Kommazahlen
```

**Warum ist das wichtig?**
Der Computer muss wissen, wie viel Speicherplatz er reservieren soll. Eine Kommazahl braucht mehr Platz als ein einfaches Ja/Nein.

---

## Was kann man mit einer Variable machen?

### 1️⃣ Wert reinlegen (Zuweisung)
```java
String name = "Pascal";   // Schachtel erstellen & befüllen
```

### 2️⃣ Wert verändern
```java
name = "Max";   // Alten Inhalt rauswerfen, neuen reinlegen
// Jetzt steht "Max" in der Schachtel, "Pascal" ist weg
```

### 3️⃣ Wert auslesen (benutzen)
```java
System.out.println(name);   // Java schaut in die Schachtel und nimmt den Wert raus
// Ausgabe: Max
```

---

## Konkretes Beispiel aus deiner Hausaufgabe

In **Aufgabe 1.2** machst du genau das:

```java
String name = "Pascal";                    // Schachtel erstellen
System.out.println("Hello " + name + "!"); // Schachtel auslesen
```

Java liest beim `+` automatisch den Inhalt der Schachtel aus und klebt ihn zusammen:
```
"Hello "  +  "Pascal"  +  "!"
              ↑
         Inhalt der Schachtel "name"
              ↓
"Hello Pascal!"
```

---

## Die wichtigste Regel: Typ muss passen! ❗

```java
int zahl = "Pascal";   // ❌ FEHLER! Text passt nicht in eine Zahlen-Schachtel
String name = 42;      // ❌ FEHLER! Zahl passt nicht in eine Text-Schachtel
String name = "42";    // ✅ OK! "42" als Text ist erlaubt
```

---

Kurz zusammengefasst in einem Satz:

> **Eine Variable ist ein benannter Speicherplatz, der einen Wert eines bestimmten Typs aufbewahrt – wie eine beschriftete Schachtel im Regal deines Computers.**

   # Recursion
   
   ## Introduction to Recursion
   
   Recursion is a programming technique where a function calls itself in order to solve a problem. It is often used to solve problems that can be broken down into smaller, similar subproblems.
   
   ### Key Concepts
   
   1. **Base Case**: The condition under which the recursion stops. It prevents infinite recursion.
   2. **Recursive Case**: The part of the function where the recursion occurs, calling the function with a modified argument.

## 📌 Aufgabe 1.4 – Zeitumrechnung

### 🎯 Was soll das Programm tun?
Der Benutzer gibt eine riesige Zahl in Sekunden ein, und das Programm rechnet diese um in **Jahre, Tage, Stunden, Minuten und Sekunden**.

**Beispiel:**
```
Eingabe:  23476234688 Sekunden
Ausgabe:  744 Jahr(e), 155 Tag(e), 16 Stunde(n), 18 Minute(n) und 8 Sekunde(n)
```

---

## 🔑 Das neue Konzept: Division & Modulo

Bevor wir den Code anschauen, musst du zwei Rechenoperationen verstehen:

### Ganzzahlige Division `/`
→ **Wie oft passt etwas komplett rein?**
```
100 / 60 = 1     (60 passt einmal komplett in 100)
```

### Modulo `%`
→ **Was bleibt übrig?**
```
100 % 60 = 40    (nach der Division bleiben 40 übrig)
```

**Zusammen ergeben sie ein vollständiges Bild:**
```
100 Sekunden = 1 Minute (Division) + 40 Sekunden Rest (Modulo)
```

---

## 🧮 Die Strategie: Von groß nach klein

Wir arbeiten uns immer von der **größten Einheit zur kleinsten** vor:

```
Schritt 1: Sekunden → Jahre       (teilen durch 60×60×24×365)
Schritt 2: Rest → Tage            (teilen durch 60×60×24)
Schritt 3: Rest → Stunden         (teilen durch 60×60)
Schritt 4: Rest → Minuten         (teilen durch 60)
Schritt 5: Rest → Sekunden        (was übrig bleibt)
```

---

## 📖 Der vollständige Code – Zeile für Zeile

```java
import Prog1Tools.IOTools;

public class Zeitumrechnung {
    public static void main(String[] args) {

        // Schritt 1: Eingabe einlesen
        long sec = IOTools.readLong("Geben Sie eine Zeitdauer in Sekunden ein:");

        // Schritt 2: Jahre berechnen
        long y = sec / (60 * 60 * 24 * 365);   // Wie viele volle Jahre?
        sec = sec % (60 * 60 * 24 * 365);       // Was bleibt übrig?

        // Schritt 3: Tage berechnen
        long d = sec / (60 * 60 * 24);          // Wie viele volle Tage?
        sec = sec % (60 * 60 * 24);             // Was bleibt übrig?

        // Schritt 4: Stunden berechnen
        long h = sec / (60 * 60);               // Wie viele volle Stunden?
        sec = sec % (60 * 60);                  // Was bleibt übrig?

        // Schritt 5: Minuten berechnen
        long min = sec / 60;                    // Wie viele volle Minuten?
        sec = sec % 60;                         // Was bleibt übrig?

        // Schritt 6: Ausgabe
        System.out.println("Das sind: " + y + " Jahr(e), " + d + 
        " Tag(e), " + h + " Stunde(n), " + min + " Minute(n) und " + 
        sec + " Sekunde(n).");
    }
}
```

**`long sec = IOTools.readLong(...)`**

> Ein Jahr hat 60×60×24×365 = **31.536.000 Sekunden**. Wir fragen: Wie oft passt das in unsere Gesamtsekunden? Das Ergebnis sind die **vollen Jahre**.

---

**`sec = sec % (60 * 60 * 24 * 365);`**
> Jetzt überschreiben wir `sec` mit dem **Rest** nach den Jahren. Diese übrigen Sekunden werden im nächsten Schritt zu Tagen umgerechnet.

```

## 🎯 Was soll das Programm tun?

Der Benutzer gibt eine riesige Zahl in **Sekunden** ein, und das Programm rechnet sie um in **Jahre, Tage, Stunden, Minuten und Sekunden**.

```
Eingabe:  23476234688 Sekunden
Ausgabe:  744 Jahr(e), 155 Tag(e), 16 Stunde(n), 18 Minute(n) und 8 Sekunde(n).
```

---

## 🔑 Das neue Konzept: Division & Modulo

Du kennst `+`, `-`, `*` – aber jetzt kommen zwei neue Rechenzeichen:

### Ganzzahlige Division `/`
→ **Wie oft passt etwas komplett rein?**
```
100 / 60 = 1     → 60 passt einmal komplett in 100
```

### Modulo `%`
→ **Was bleibt übrig?**
```
100 % 60 = 40    → nach der Division bleiben 40 Sekunden übrig
```

### Zusammen ergeben sie ein vollständiges Bild:
```
100 Sekunden = 1 volle Minute  +  40 Sekunden Rest
                   (/ 60)              (% 60)
```

---

## 🧮 Die Strategie: Immer von groß nach klein

```
Gesamtsekunden ÷ Sekunden pro Jahr  → volle Jahre,   Rest weiterrechnen
Rest           ÷ Sekunden pro Tag   → volle Tage,    Rest weiterrechnen
Rest           ÷ Sekunden pro Stunde→ volle Stunden, Rest weiterrechnen
Rest           ÷ 60                 → volle Minuten, Rest = Sekunden
```

---

## 📖 Der Code Schritt für Schritt

### Schritt 1: Eingabe einlesen
```java
long sec = IOTools.readLong("Geben Sie eine Zeitdauer in Sekunden ein:");
```
> Kennst du schon aus 1.3! Nur zwei Unterschiede:
> - `long` statt `String` → weil wir eine sehr große **Zahl** einlesen
> - `readLong` statt `readLine` → weil wir eine **Zahl** wollen, keinen Text

---

### Schritt 2: Jahre berechnen
```java
long y = sec / (60 * 60 * 24 * 365);   // Wie viele volle Jahre?
sec = sec % (60 * 60 * 24 * 365);      // Was bleibt übrig?
```
> - `60 * 60 * 24 * 365` = Sekunden pro Jahr = **31.536.000**
> - Erste Zeile: Wie viele volle Jahre passen rein? → landet in `y`
> - Zweite Zeile: `sec` wird überschrieben mit dem Rest!

---

### Schritt 3: Tage berechnen
```java
long d = sec / (60 * 60 * 24);   // Wie viele volle Tage?

```
> Exakt dasselbe Prinzip – nur jetzt mit Sekunden pro Tag = **86.400**

---

### Schritt 4: Stunden berechnen
```java
long h = sec / (60 * 60);   // Wie viele volle Stunden?
sec = sec % (60 * 60);      // Was bleibt übrig?
```
> Sekunden pro Stunde = **3.600**

---

### Schritt 5: Minuten & Sekunden
```java

```

   ## Unary Operators
   
   In programming, unary operators are used to manipulate a single operand. The most useful unary operators for numbers are pre-increment, post-increment, pre-decrement, and post-decrement. Let's look at an example to illustrate how these operators work.
   
   ```python
   x = 42
   a = x++  # Post-increment: assigns 42 to a, then x becomes 43
   b = ++x  # Pre-increment: x becomes 44, then assigns 44 to b
   c = x--  # Post-decrement: assigns 44 to c, then x becomes 43
   d = --x  # Pre-decrement: x becomes 42, then assigns 42 to d
   ```
   
   ### Explanation
   
   - Both `++x` and `x++` increase the value of `x` by one. The difference is whether `x` is incremented before (`++x`) or after (`x++`) the expression is evaluated.
   - In line 4, the expression on the right evaluates to 42, assigns 42 to `a`, and then increases the value stored in `x` to 43.
   - In line 5, `x` is increased to 44, the expression evaluates to 44, and that value is stored in `b`.
   - For the decrement operations, line 6 evaluates the expression on the right to 44, assigns 44 to `c`, and then decreases the value stored in `x` to 43.
   - Line 7 decreases the value stored in `x` to 42, evaluates the expression on the right to 42, and then stores that value in `d`.
   
   To avoid confusion with these operators, it is easiest to consider the order of operations: If the increment (`++`) or decrement (`--`) comes first, the operation is performed before evaluating the expression. If the variable name comes first, the expression is evaluated before incrementing or decrementing the variable.

   ### Overview of Object-Oriented Programming
   
   Object-Oriented Programming (OOP) is a programming paradigm that uses "objects" to represent data and methods to manipulate that data. The key concepts of OOP include:
   
   - **Classes and Objects**
   - **Encapsulation**
   - **Inheritance**
   - **Polymorphism**
   
   ### 1. Classes and Objects
   
   A class is a blueprint for creating objects. An object is an instance of a class.
   
   ```python
   class Dog:
   def __init__(self, name):
   self.name = name
   
   def bark(self):
   return f"{self.name} says woof!"
   
   # Creating an object of the Dog class
   my_dog = Dog("Buddy")
   print(my_dog.bark())  # Output: Buddy says woof!
   ```
   
   ### 2. Encapsulation
   
   Encapsulation is the bundling of data and methods that operate on that data within one unit, typically a class. It restricts direct access to some of the object's components.
   
   ```python
   class BankAccount:
   def __init__(self, balance=0):
   self.__balance = balance  # Private attribute
   
   def deposit(self, amount):
   self.__balance += amount
   
   def get_balance(self):
   return self.__balance
   
   account = BankAccount()
   account.deposit(100)
   print(account.get_balance())  # Output: 100
   ```
   
   ### 3. Inheritance
   
   Inheritance allows a class to inherit attributes and methods from another class.
   
   ```python
   class Animal:
   def speak(self):
   return "Animal speaks"
   
   class Cat(Animal):
   def speak(self):
   return "Cat meows"
   
   my_cat = Cat()
   print(my_cat.speak())  # Output: Cat meows
   ```
   
   ### 4. Polymorphism
   
   Polymorphism allows methods to do different things based on the object it is acting upon.
   
   ```python
   def animal_sound(animal):
   print(animal.speak())
   
   animal_sound(my_cat)  # Output: Cat meows
   animal_sound(Dog("Rex"))  # Output: Rex says woof!
   ```
   
   ### Summary
   
   Object-Oriented Programming is a powerful paradigm that helps in organizing code and making it more reusable and maintainable.

## 🎯 Was soll das Programm tun?

Der Benutzer gibt eine Zahl ein, und das Programm berechnet die **Quadratwurzel** davon:

```
Eingabe:  64
Ausgabe:  Die Wurzel aus 64 ist 8.
```

---

## 🔑 Zwei neue Konzepte

### 1. `Math.sqrt()` – Wurzel berechnen
Java hat eine eingebaute Mathematik-Bibliothek namens `Math`. Damit kannst du die Wurzel einer Zahl berechnen:

```java
double wurzel = Math.sqrt(64);   // wurzel = 8.0
```

> `Math.sqrt` bedeutet wörtlich: "Mathematik, berechne die Quadratwurzel!" Das Ergebnis ist immer eine Kommazahl (`double`) – deshalb `double wurzel`.

---

### 2. Typecast – Kommazahl → Ganzzahl
`Math.sqrt` gibt immer eine Kommazahl zurück (`8.0`), aber die Aufgabe will eine **ganze Zahl** (`8`). Dafür benutzt man einen **Typecast**:

```java
double wurzel = 8.0;
int ganzzahl = (int) wurzel;   // ganzzahl = 8
//              ↑
//         Das ist der Typecast – du sagst Java: "Behandle das als int"
```

> Der Typecast schneidet einfach die Nachkommastellen ab:
> ```
> 8.9  → (int) → 8    (nicht gerundet, einfach abgeschnitten!)
> 8.1  → (int) → 8
> ```

---

## 📖 Der vollständige Code:

```java
import Prog1Tools.IOTools;

public class Wurzel {
    public static void main(String[] args) {
        int num = IOTools.readInt("Geben Sie eine Zahl ein:");
        double wurzel = Math.sqrt(num);
        System.out.println("Die Wurzel aus " + num + " ist " + (int) wurzel + ".");
    }
}
```

---

## 🔍 Zeile für Zeile erklärt:

**`int num = IOTools.readInt("Geben Sie eine Zahl ein:")`**
> Kennst du schon! Diesmal lesen wir eine `int` Zahl ein – also eine normale kleine ganze Zahl.

---

**`double wurzel = Math.sqrt(num);`**
> Java berechnet die Wurzel von `num` und speichert das Ergebnis in `wurzel`. Das Ergebnis ist eine Kommazahl (`double`).

---

**`System.out.println("Die Wurzel aus " + num + " ist " + (int) wurzel + ".");`**
> Bei der Ausgabe wird `(int) wurzel` direkt in der Ausgabe umgewandelt – die Nachkommastellen werden abgeschnitten:
> ```
> wurzel = 8.0  →  (int) wurzel = 8
> ```

---

## ▶️ Programmablauf:

```

             ↓

             ↓

             ↓

```

        long y   = sec / (60 * 60 * 24 * 365);   // Volle Jahre
        sec      = sec % (60 * 60 * 24 * 365);   // Rest nach Jahren

        long d   = sec / (60 * 60 * 24);          // Volle Tage
        sec      = sec % (60 * 60 * 24);          // Rest nach Tagen

        long h   = sec / (60 * 60);               // Volle Stunden
        sec      = sec % (60 * 60);               // Rest nach Stunden

        long min = sec / 60;                      // Volle Minuten
        sec      = sec % 60;                      // Rest = Sekunden

        System.out.println("Das sind: " + y + " Jahr(e), " + d + 
        " Tag(e), " + h + " Stunde(n), " + min + " Minute(n) und " + 
        sec + " Sekunde(n).");
    }
}
