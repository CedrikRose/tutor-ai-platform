  ## Search Algorithms
  
  ### Introduction
  Search algorithms are fundamental to computer science and are used to retrieve information stored within data structures. They can be broadly categorized into two types: **linear search** and **binary search**.
  
  ### Linear Search
  Linear search is the simplest search algorithm. It checks each element in a list until the desired element is found or the list ends.
  
  #### Algorithm
  ```python
  def linear_search(arr, target):
  for index, value in enumerate(arr):
  if value == target:
  return index
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(n)
  - **Space Complexity**: O(1)
  
  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays.

  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays. It divides the search interval in half repeatedly until the target value is found.
  
  #### Algorithm
  ```python
  def binary_search(arr, target):
  left, right = 0, len(arr) - 1
  while left &#x3C;= right:
  mid = left + (right - left) // 2
  if arr[mid] == target:
  return mid
  elif arr[mid] &#x3C; target:
  left = mid + 1
  else:
  right = mid - 1
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(log n)
  - **Space Complexity**: O(1)
  
  ### Comparison of Search Algorithms
  
  | Algorithm      | Time Complexity | Space Complexity |
  |----------------|-----------------|------------------|
  | Linear Search  | O(n)            | O(1)             |
  | Binary Search  | O(log n)        | O(1)             |
  
  ### Conclusion
  Choosing the right search algorithm depends on the data structure and the specific requirements of the application. For unsorted data, linear search is appropriate, while binary search is optimal for sorted data.

STUDENT: Wie funktioniert Selection Sort in Java?

ASSISTENT: # Selection Sort in Java

## Grundprinzip

Selection Sort funktioniert nach folgendem Prinzip:

1. **Finde das kleinste Element** im unsortierten Teil des Arrays
2. **Tausche es** mit dem ersten Element des unsortierten Teils
3. **Verschiebe die Grenze** zwischen sortiertem und unsortiertem Teil um eine Position nach rechts
4. **Wiederhole**, bis das gesamte Array sortiert ist

---

## Visualisierung

```
[64, 25, 12, 22, 11]   → finde Minimum (11), tausche mit Index 0
[11, 25, 12, 22, 64]   → finde Minimum (12), tausche mit Index 1
[11, 12, 25, 22, 64]   → finde Minimum (22), tausche mit Index 2
[11, 12, 22, 25, 64]   → finde Minimum (25), tausche mit Index 3
[11, 12, 22, 25, 64]   → fertig ✓
 ↑____________↑
 sortiert   | unsortiert
```

---

## Java-Implementierung

```java
public class SelectionSort {

    public static void selectionSort(int[] arr) {
        int n = arr.length;

        // Äußere Schleife: Grenze des sortierten Bereichs
        for (int i = 0; i < n - 1; i++) {

            // Schritt 1: Index des Minimums im unsortierten Teil finden
            int minIndex = i;
            for (int j = i + 1; j < n; j++) {
                if (arr[j] < arr[minIndex]) {
                    minIndex = j;
                }
            }

            // Schritt 2: Minimum mit erstem unsortierten Element tauschen
            int temp = arr[minIndex];
            arr[minIndex] = arr[i];
            arr[i] = temp;
        }
    }

    public static void main(String[] args) {
        int[] arr = {64, 25, 12, 22, 11};
        selectionSort(arr);

        // Ausgabe: 11 12 22 25 64
        for (int val : arr) {
            System.out.print(val + " ");
        }
    }
}
```

---

## Komplexität

| Eigenschaft | Wert |
|---|---|
| **Zeit (Best Case)** | O(n²) |
| **Zeit (Worst Case)** | O(n²) |
| **Speicher** | O(1) |

> ⚠️ **Wichtig:** Selection Sort hat **immer O(n²)**, da der innere Suchdurchlauf unabhängig vom Eingabezustand immer vollständig ausgeführt wird.

---

## Vergleich mit anderen Sortieralgorithmen

Laut den Kursmaterialien gibt es effizientere Alternativen:

| Algorithmus | Durchschnitt | Geeignet für |
|---|---|---|
| Selection Sort | O(n²) | Kleine Arrays |
| Merge Sort | O(n log n) | Große Arrays |
| Quick Sort | O(n log n) | Allgemein |

**Fazit:** Selection Sort ist einfach zu verstehen, aber für große Datensätze weniger geeignet als Merge Sort oder Quick Sort.
