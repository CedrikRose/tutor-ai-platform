  ## Search Algorithms
  
  ### Introduction
  Search algorithms are fundamental to computer science and are used to retrieve information stored within data structures. They can be broadly categorized into two types: **linear search** and **binary search**.
  
  ### Linear Search
  Linear search is the simplest search algorithm. It checks each element in a list until the desired element is found or the list ends.
  
  #### Algorithm
  ```python
  def linear_search(arr, target):
  for index, value in enumerate(arr):
  if value == target:
  return index
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(n)
  - **Space Complexity**: O(1)
  
  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays.

  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays. It divides the search interval in half repeatedly until the target value is found.
  
  #### Algorithm
  ```python
  def binary_search(arr, target):
  left, right = 0, len(arr) - 1
  while left &#x3C;= right:
  mid = left + (right - left) // 2
  if arr[mid] == target:
  return mid
  elif arr[mid] &#x3C; target:
  left = mid + 1
  else:
  right = mid - 1
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(log n)
  - **Space Complexity**: O(1)
  
  ### Comparison of Search Algorithms
  
  | Algorithm      | Time Complexity | Space Complexity |
  |----------------|-----------------|------------------|
  | Linear Search  | O(n)            | O(1)             |
  | Binary Search  | O(log n)        | O(1)             |
  
  ### Conclusion
  Choosing the right search algorithm depends on the data structure and the specific requirements of the application. For unsorted data, linear search is appropriate, while binary search is optimal for sorted data.

ASSISTENT: # Selection Sort in Java

Selection Sort ist ein einfacher, intuitiver Sortieralgorithmus. Lass mich dir das Konzept direkt und vollständig erklären!

---

## 💡 Die Grundidee

Stell dir vor, du hast eine Reihe unsortierter Zahlen und möchtest sie aufsteigend sortieren. Selection Sort macht dabei Folgendes:

> **In jedem Durchlauf sucht der Algorithmus das kleinste Element im noch unsortierten Teil des Arrays und tauscht es an die richtige Position.**

Das Ergebnis: Nach jedem Durchlauf wächst der sortierte Teil des Arrays um genau ein Element.

---

## 🔍 Schritt-für-Schritt am Beispiel

Starten wir mit dem Array: `[5, 3, 8, 1, 4]`

| Durchlauf | Array-Zustand | Aktion |
|-----------|--------------|--------|
| Start | `[5, 3, 8, 1, 4]` | – |
| 1 | `[`**1**`, 3, 8, 5, 4]` | Minimum (1) gefunden → tausche mit Position 0 |
| 2 | `[1,`**3**`, 8, 5, 4]` | Minimum (3) bereits an richtiger Stelle |
| 3 | `[1, 3,`**4**`, 5, 8]` | Minimum (4) gefunden → tausche mit Position 2 |
| 4 | `[1, 3, 4,`**5**`, 8]` | Minimum (5) bereits an richtiger Stelle |
| Fertig | `[1, 3, 4, 5, 8]` | ✅ |

---

## ☕ Implementierung in Java

```java
public static void selectionSort(int[] arr) {
    int n = arr.length;

    for (int i = 0; i < n - 1; i++) {
        // Annahme: Das Element an Position i ist das aktuelle Minimum
        int minIndex = i;

        // Suche das tatsächliche Minimum im unsortierten Teil
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;  // Neues Minimum gefunden
            }
        }

        // Tausche das gefundene Minimum an die Position i
        int temp = arr[minIndex];
        arr[minIndex] = arr[i];
        arr[i] = temp;
    }
}
```

### Was passiert hier genau?
- **Äußere Schleife (`i`):** Läuft durch jede Position des Arrays – hier soll am Ende das Minimum landen.
- **Innere Schleife (`j`):** Durchsucht den *unsortierten* Teil (alles rechts von `i`) nach dem kleinsten Element.
- **Tausch:** Das gefundene Minimum wird mit dem Element an Position `i` getauscht.

---

## ⏱️ Komplexität

| | Komplexität | Erklärung |
|---|---|---|
| **Zeit** | O(n²) | Zwei verschachtelte Schleifen über n Elemente |
| **Speicher** | O(1) | Nur eine temporäre Variable (`temp`) nötig – kein Extra-Array |

Die O(n²)-Zeitkomplexität gilt für **alle Fälle** (Best, Average, Worst) – im Gegensatz z.B. zu Bubble Sort, das im besten Fall O(n) erreichen kann.

---

## 🆚 Kurzer Vergleich mit anderen Sortieralgorithmen

| Algorithmus | Best Case | Average Case | Worst Case |
|---|---|---|---|
| Selection Sort | O(n²) | O(n²) | O(n²) |
| Bubble Sort | O(n) | O(n²) | O(n²) |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) |

Selection Sort ist damit für große Datenmengen **nicht empfehlenswert**, aber wegen seiner Einfachheit ein gutes Lernbeispiel.
