  ### Introduction
  Search algorithms are fundamental to computer science and are used to retrieve information stored within data structures. They can be broadly categorized into two types: **linear search** and **binary search**.
  
  ### Linear Search
  Linear search is the simplest search algorithm. It checks each element in a list until the desired element is found or the list ends.
  
  #### Algorithm
  ```python
  def linear_search(arr, target):
  for index, value in enumerate(arr):
  if value == target:
  return index
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(n)
  - **Space Complexity**: O(1)
  
  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays.

ASSISTENT: # Was sind Algorithmen? 🧩

Ein **Algorithmus** ist eine **endliche, präzise Folge von Anweisungen**, die ein bestimmtes Problem löst oder eine Aufgabe erfüllt. Stell dir einen Algorithmus wie ein Kochrezept vor: Er beschreibt Schritt für Schritt, was zu tun ist, um von einem Ausgangszustand (Zutaten) zu einem Ergebnis (fertiges Gericht) zu gelangen.

---

## Kernmerkmale eines Algorithmus

| Merkmal | Bedeutung |
|---|---|
| **Endlichkeit** | Der Algorithmus muss nach einer endlichen Anzahl von Schritten terminieren |
| **Eindeutigkeit** | Jeder Schritt ist klar und unmissverständlich definiert |
| **Eingabe** | Er nimmt (optional) Eingabedaten entgegen |
| **Ausgabe** | Er produziert ein definiertes Ergebnis |
| **Ausführbarkeit** | Jeder Schritt muss tatsächlich durchführbar sein |

---

## Algorithmen in Java – Was bedeutet das konkret?

In Java implementierst du Algorithmen als **Methoden**, die auf Datenstrukturen (z. B. Arrays, Listen) operieren. Die Sprache selbst ändert nichts am Konzept des Algorithmus – Java ist nur das *Werkzeug*, mit dem du ihn ausdrückst.

### Beispiel: Linearer Suchalgorithmus in Java

Ein klassischer Einstiegsalgorithmus ist die **lineare Suche**: Du durchsuchst ein Array Element für Element, bis du den gesuchten Wert findest.

```java
public static int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i; // Gefunden! Index zurückgeben
        }
    }
    return -1; // Nicht gefunden
}
```

**Was passiert hier Schritt für Schritt?**
1. Starte beim ersten Element (Index `0`)
2. Vergleiche das aktuelle Element mit dem gesuchten Wert (`target`)
3. Wenn gleich → gib den Index zurück ✅
4. Wenn nicht → gehe zum nächsten Element
5. Wenn das Array zu Ende ist → gib `-1` zurück (nicht gefunden) ❌

---

## Warum sind Algorithmen wichtig?

Für dasselbe Problem kann es **viele verschiedene Algorithmen** geben – und sie können sich drastisch in ihrer **Effizienz** unterscheiden. Das misst man mit der sogenannten **Komplexitätstheorie** (z. B. Big-O-Notation).

Zum Beispiel:
- **Lineare Suche**: Im schlimmsten Fall muss jedes Element geprüft werden → **O(n)**
- **Binäre Suche** (auf sortierten Arrays): Halbiert den Suchraum bei jedem Schritt → **O(log n)** – deutlich schneller bei großen Datenmengen!
