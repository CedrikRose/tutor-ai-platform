STUDENT: Was ist die Komplexitätstheorie in Java?

ASSISTENT: # Komplexitätstheorie in Java

Die **Komplexitätstheorie** beschreibt, wie der **Zeit- und Speicherbedarf** eines Algorithmus mit wachsender Eingabegröße zunimmt.

---

## Big-O-Notation

Die wichtigste Notation zur Beschreibung der Komplexität:

| Notation | Name | Beispiel |
|----------|------|---------|
| O(1) | Konstant | Array-Zugriff |
| O(log n) | Logarithmisch | Binäre Suche |
| O(n) | Linear | Lineare Suche |
| O(n log n) | Linearithmisch | Merge Sort |
| O(n²) | Quadratisch | Bubble Sort |
| O(2ⁿ) | Exponentiell | Fibonacci rekursiv |

---

## Java-Beispiele

### O(1) – Konstante Komplexität
```java
public int getFirst(int[] array) {
    return array[0]; // Immer gleich schnell
}
```

### O(n) – Lineare Komplexität
```java
public int linearSearch(int[] array, int target) {
    for (int i = 0; i < array.length; i++) { // n Schritte
        if (array[i] == target) return i;
    }
    return -1;
}
```

### O(n²) – Quadratische Komplexität
```java
public void bubbleSort(int[] array) {
    for (int i = 0; i < array.length; i++) {        // n
        for (int j = 0; j < array.length - 1; j++) { // n
            if (array[j] > array[j+1]) {
                int temp = array[j];
                array[j] = array[j+1];
                array[j+1] = temp;
            }
        }
    }
}
```

### O(log n) – Logarithmische Komplexität
```java
public int binarySearch(int[] array, int target) {
    int left = 0, right = array.length - 1;
    
    while (left <= right) {
        int mid = (left + right) / 2;
        if (array[mid] == target) return mid;
        else if (array[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

### O(2ⁿ) – Exponentielle Komplexität
```java
public int fibonacci(int n) {
    if (n <= 1) return n;
    return fibonacci(n - 1) + fibonacci(n - 2); // Sehr langsam!
}
```

## Zeitkomplexität vs. Raumkomplexität

```java
// Hohe Raumkomplexität O(n), aber Zeit O(1) für Lookup
HashMap<Integer, String> map = new HashMap<>();

// Niedrige Raumkomplexität O(1), aber Zeit O(n) für Suche
LinkedList<String> list = new LinkedList<>();
```

---

## Java Collections und ihre Komplexität

| Datenstruktur | Zugriff | Suche | Einfügen | Löschen |
|---------------|---------|-------|----------|---------|
| ArrayList | O(1) | O(n) | O(n) | O(n) |
| LinkedList | O(n) | O(n) | O(1) | O(1) |
| HashMap | O(1) | O(1) | O(1) | O(1) |
| TreeMap | O(log n) | O(log n) | O(log n) | O(log n) |
| HashSet | O(1) | O(1) | O(1) | O(1) |

---

## Zusammenfassung

```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)
 Gut                                              Schlecht
```

Die Komplexitätstheorie hilft dabei, **effiziente Algorithmen** zu wählen und **Performance-Probleme** frühzeitig zu erkennen.
