STUDENT: Was ist die Komplexitätstheorie in Java?

ASSISTENT: ## Komplexitätstheorie in Java

Die **Komplexitätstheorie** ist kein spezifisches Java-Konzept, sondern ein **fundamentales Thema der Informatik** im Allgemeinen.

---

### Was ist Komplexitätstheorie?

Die Komplexitätstheorie beschäftigt sich mit der **Effizienz von Algorithmen**, insbesondere:

- ⏱️ **Zeitkomplexität** – Wie viele Schritte braucht ein Algorithmus?
- 💾 **Speicherkomplexität** – Wie viel Speicher wird benötigt?

---

### Die Big-O-Notation

Das wichtigste Werkzeug ist die **Big-O-Notation**, z.B.:

| Notation | Bezeichnung | Beispiel |
|----------|-------------|---------|
| O(1) | Konstant | Array-Zugriff |
| O(log n) | Logarithmisch | Binäre Suche |
| O(n) | Linear | Einfache Schleife |
| O(n²) | Quadratisch | Verschachtelte Schleifen |
