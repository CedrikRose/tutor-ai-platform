ASSISTENT: # Komplexitätstheorie in Java? 🤔

Das ist eine interessante Frage! Ich möchte kurz einhaken, bevor wir loslegen:

**Komplexitätstheorie** ist eigentlich kein Java-spezifisches Konzept – sie ist ein fundamentales Thema der **Informatik/Theoretischen Informatik** allgemein.

---

## Lass mich dich etwas fragen:

Meinst du vielleicht eines dieser Themen?

1. **Algorithmische Komplexität** (z.B. O-Notation, Laufzeitanalyse) – *"Wie schnell ist mein Algorithmus?"*

2. **Theoretische Komplexitätstheorie** (P vs. NP, Komplexitätsklassen) – *"Welche Probleme sind grundsätzlich schwer lösbar?"*

3. **Code-Komplexität in Java** (z.B. wie komplex/lesbar ist mein Code strukturiert)

  ### 1. Introduction to Programming
  Programming is the process of creating a set of instructions that tell a computer how to perform a task. It involves writing code in a programming language.
  
  ### 2. Basic Concepts
  - **Variables**: Used to store data values.
  - **Data Types**: Different types of data (e.g., integers, floats, strings).
  - **Operators**: Symbols that perform operations on variables and values.
  
  #### Example:
  ```python
  # This is a comment
  x = 5           # Integer
  y = 3.14        # Float
  name = "Alice"  # String
  ```
  
  ### 3. Control Structures
  Control structures dictate the flow of control in a program. The most common types are:
  - **Conditional Statements**: `if`, `else`, `elif`
  - **Loops**: `for`, `while`
  
  #### Example:
  ```python
  # Conditional statement
  if x > 0:
  print("x is positive")
  else:
  print("x is non-positive")
  
  # Loop
  for i in range(5):
  print(i)
  ```
  
  ### 4. Functions
  Functions are reusable pieces of code that perform a specific task. They can take inputs and return outputs.
  
  #### Example:
  ```python
  def add(a, b):
  return a + b
  
  result = add(5, 3)
  print(result)  # Output: 8
  ```
  
  ### 5. Data Structures
  Data structures are ways to organize and store data. Common data structures include:
  - **Lists**
  - **Tuples**
  - **Dictionaries**
  - **Sets**
  
  #### Example:
  ```python
  # List
  fruits = ["apple", "banana", "cherry"]
  
  # Dictionary
  person = {"name": "Alice", "age": 25}
  ```
