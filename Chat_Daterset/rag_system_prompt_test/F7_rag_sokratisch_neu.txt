STUDENT: Was ist die Komplexitätstheorie in Java?

ASSISTENT: # Komplexitätstheorie – eine wichtige Klarstellung! 🎯

Hier lohnt sich eine kurze, aber wichtige Unterscheidung, bevor wir tiefer einsteigen:

## Komplexitätstheorie ist kein Java-Konzept

Die **Komplexitätstheorie** (genauer: *algorithmische Komplexität* oder *Laufzeitkomplexität*) ist **kein Java-spezifisches Thema**, sondern ein fundamentales Konzept der **Informatik und Mathematik**, das für **alle Programmiersprachen** gilt.

In Java (oder Python, C++, etc.) *analysiert* man die Komplexität von Algorithmen – aber die Theorie selbst ist sprachunabhängig.

---

## Was ist Komplexitätstheorie? 📊

Die Komplexitätstheorie beschäftigt sich mit der Frage:

> **Wie wächst der Ressourcenverbrauch (Zeit, Speicher) eines Algorithmus, wenn die Eingabegröße wächst?**

Das wichtigste Werkzeug dafür ist die sogenannte **Landau-Notation** (auch: **Big-O-Notation**).

---

## Die Big-O-Notation

Die **O-Notation** beschreibt das **asymptotische Wachstumsverhalten** – also: Wie verhält sich der Algorithmus bei *sehr großen* Eingaben $n$?

| Notation | Name | Beispiel |
|---|---|---|
| $O(1)$ | Konstant | Array-Zugriff per Index |
| $O(\log n)$ | Logarithmisch | Binäre Suche |
| $O(n)$ | Linear | Einfache Schleife über alle Elemente |
| $O(n \log n)$ | Linearithmisch | Mergesort, Heapsort |
| $O(n^2)$ | Quadratisch | Verschachtelte Schleifen |
| $O(2^n)$ | Exponentiell | Naiver Algorithmus für das Rucksackproblem |

### Anschauliches Beispiel in Java:

```java
// O(n) – lineare Komplexität
for (int i = 0; i < n; i++) {
    System.out.println(i); // wird n-mal ausgeführt
}

// O(n²) – quadratische Komplexität
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        System.out.println(i + ", " + j); // wird n × n = n² mal ausgeführt
    }
}
```

---

## Warum ist das wichtig?

Stell dir vor, du hast $n = 1.000.000$ Elemente:

- Ein $O(n)$-Algorithmus führt ~1.000.000 Schritte aus ✅
- Ein $O(n^2)$-Algorithmus führt ~1.000.000.000.000 Schritte aus ❌ (dauert ewig!)

Die Wahl des richtigen Algorithmus kann also den Unterschied zwischen **Millisekunden** und **Jahren** Laufzeit bedeuten.
