  # IV-A: Algorithms
  
  ## Search Algorithms
  
  ### Introduction
  Search algorithms are fundamental to computer science and are used to retrieve information stored within data structures. They can be broadly categorized into two types: **linear search** and **binary search**.
  
  ### Linear Search
  Linear search is the simplest search algorithm. It checks each element in a list until the desired element is found or the list ends.
  
  #### Algorithm
  ```python
  def linear_search(arr, target):
  for index, value in enumerate(arr):
  if value == target:
  return index
  return -1
  ```
  
  #### Complexity
  - **Time Complexity**: O(n)
  - **Space Complexity**: O(1)
  
  ### Binary Search
  Binary search is a more efficient algorithm that works on sorted arrays.

ASSISTENT: # Algorithmen in Java

## Definition

Ein **Algorithmus** ist eine **endliche Folge von klar definierten Anweisungen**, die ein Problem lösen oder eine Aufgabe ausführen. In Java werden Algorithmen als **Methoden oder Programme** implementiert.

---

## Wichtige Eigenschaften von Algorithmen

- ✅ **Endlichkeit** – muss terminieren
- ✅ **Eindeutigkeit** – klare, nicht-mehrdeutige Schritte
- ✅ **Korrektheit** – liefert das richtige Ergebnis
- ✅ **Effizienz** – möglichst sparsam mit Zeit und Speicher

---

## Hauptkategorien aus der Vorlesung

### 🔍 Suchalgorithmen
| Algorithmus | Zeitkomplexität | Voraussetzung |
|---|---|---|
| **Linear Search** | O(n) | Unsortiertes Array möglich |
| **Binary Search** | O(log n) | Array muss sortiert sein |

**Beispiel – Linear Search in Java:**
```java
// Durchsucht jedes Element nacheinander
int linearSearch(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i; // Index gefunden
        }
    }
    return -1; // Nicht gefunden
}
```

---

### 📊 Sortieralgorithmen
- **Bubble Sort**
- **Selection Sort**
- **Merge Sort**
- **Quick Sort**

---

## Komplexitätstheorie (Big-O-Notation)

Die **Effizienz** eines Algorithmus wird mit der **Big-O-Notation** gemessen:

- **O(1)** → konstante Zeit (z.B. Array-Zugriff)
- **O(n)** → lineare Zeit (z.B. Linear Search)
- **O(log n)** → logarithmische Zeit (z.B. Binary Search)

---

## Zusammenfassung

> 💡 Die **Wahl des richtigen Algorithmus** ist entscheidend für die Performance eines Programms – besonders bei großen Datenmengen!
